# Circuit Lab 🧪⚡

Circuit Lab is an interactive, web-based virtual circuit building platform that allows users to design and simulate basic digital logic circuits using ICs.  
Instead of drag-and-drop blocks, Circuit Lab mimics a **real-world digital trainer kit**, where users connect wires between IC pins, switches, LEDs, VCC, and GND — similar to how circuits are built in physical labs.

🚧 **Status:** Ongoing Project

---

## 🚀 Features

- 🧠 Virtual digital trainer kit interface
- 🔌 IC-based circuit building (AND, OR, NOT, NAND, NOR, etc.)
- 🔗 Pin-to-pin wiring system (no drag-and-drop blocks)
- 🎚 Input switches to control logic states
- 💡 Output LEDs to visualize results
- ⚡ Power ON/OFF simulation
- 🧮 Logic evaluation engine for IC behavior

## 🧩 Project Concept

Circuit Lab focuses on **learning-by-doing**, helping students understand:
- Digital logic gates
- IC pin configurations
- Real-world wiring logic
- Circuit debugging skills

The interface is inspired by **physical electronics trainer boards**, making it especially useful for:
- Diploma & engineering students
- Beginners in digital electronics
- Virtual lab practice
